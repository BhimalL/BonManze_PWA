- **`d72937f`** — harmonized the Actions column's `<td>` padding to `px-3.5 py-3.5` (matching every other column), and restored `max-w-[180px]` plus the `title` hover tooltip on the entity badge alongside the 2-line wrap — so the badge now wraps *and* has a width ceiling, rather than one or the other. Full automated suite (`tsc`, `testCheckoutFlow.js`, `testOrderEditCancel.js`, `testMultiEntity.js`, `testSettingsRBAC.js`, 18/18) re-run clean before this commit.
- **`dff5dff`** — added `useEffect(() => { setEntityFilter('all'); }, [tab]);` so the entity filter actually resets to "All" on tab navigation, per the original scope's no-persistence requirement. - **`7755455`** — docs-only commit recording that Bhimal's full click-through on `localhost:3000` confirmed, live: all four screens filter correctly by active and retired entities, Orders by Dish keeps its single combined count, Customer Directory's badges wrap/tooltip/fit cleanly with no overflow, and the entity filter resets to "All Entities" on tab navigation.
