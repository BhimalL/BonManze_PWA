## 2026-09-10 — Entity-Restricted Views UI & Navigation Refinements (Antigravity)

**Commits:** [`86aea5d`](https://github.com/BhimalL/BonManze_PWA/commit/86aea5daf5af8cae8ed072ae3bc5f9df8b5ebd2c) "fix: Add badge truncation and tooltips for long entity names in tables and cards", [`6773cbe`](https://github.com/BhimalL/BonManze_PWA/commit/6773cbea3ceae5f189eac721fa50ec90d96b2fae) "fix: Reduce Customer Directory table cell padding to eliminate horizontal scrollbar and enable 2-line entity badge text wrapping", [`d72937f`](https://github.com/BhimalL/BonManze_PWA/commit/d72937fd91308b4261e8a89e8f0158b0d2d9aa67) "fix(operations): harmonize Customer Directory Actions padding to px-3.5 and constrain entity badge width max-w-[180px]", [`dff5dff`](https://github.com/BhimalL/BonManze_PWA/commit/dff5dff9e0a5a998420b2e87a046ea547bdcebf5) "fix(operations): reset entity filter to all on tab navigation", and [`7755455`](https://github.com/BhimalL/BonManze_PWA/commit/7755455ce3d9f25de8eca2e6540ae231f94952cd) "docs: record Entity-Restricted Operations Views phase as fully confirmed working" — all pushed to `main`.

**Verified:** `npx tsc --noEmit` clean, 4 automated test suites pass. **Confirmed working:** Bhimal's live browser click-through on `localhost:3000` confirmed all four screens filter correctly by active and retired entities, Customer Directory's badges wrap/tooltip/fit cleanly with no overflow, and the entity filter resets to "All Entities" on tab navigation.

**Changes:**
- **`86aea5d` — Badge truncation & tooltips.** Long entity names were overflowing their badges in Delivery List, Payments, and Customer Directory, found on Bhimal's first live click-through pass. Added `truncate max-w-[180px]` to all three badges, a `max-w-[200px]` constraint on Customer Directory's `ENTITY` column, and a `title={...}` hover tooltip showing the full name.
- **`6773cbe` — Cell padding cut, badge switched to wrap (regressed two things `86aea5d` had just added).** Truncation alone didn't stop the Customer Directory table from scrolling horizontally, so this changed approach: cell padding cut from `px-6 py-4` to `px-3.5 py-3.5`, and the entity badge changed from single-line truncate-with-tooltip to `whitespace-normal text-left leading-tight` (2-line wrap instead of clipping). In making that change, this commit also dropped the `86aea5d` width caps and missed the Actions column's `<td>` padding (which stayed at `px-6 py-4`, inconsistent with the rest of the table) — both caught on the next pass, not this one.
- **`d72937f` — Fixed both regressions from `6773cbe`.** Harmonized the Actions column's `<td>` padding to `px-3.5 py-3.5` (matching every other column), and restored `max-w-[180px]` plus the `title` hover tooltip on the entity badge alongside the 2-line wrap — so the badge now wraps *and* has a width ceiling, rather than one or the other. Full automated suite (`tsc` + `testCheckoutFlow.js`, `testOrderEditCancel.js`, `testMultiEntity.js`, `testSettingsRBAC.js`, 18/18) re-run clean before this commit.
- **`dff5dff` — Reset-on-navigation.** Added `useEffect(() => { setEntityFilter('all'); }, [tab]);` in `Operations.tsx` so the entity filter actually resets to "All" when switching tabs — Operations is one long-lived component with tab state, not a router that unmounts/remounts screens, so this needed an explicit effect rather than happening automatically.
- **`7755455` — Docs.** Recorded the finalized scope, full six-commit history, and the confirmed live click-through result in `docs/BonManzE_EntityRestrictedViews_Scope.md`.

**Net result:** the Customer Directory entity-badge column took three real passes (`86aea5d` → `6773cbe` → `d72937f`) to settle, including one commit that introduced two regressions while fixing the original bug — on top of `bf51908`'s Rules of Hooks crash fix logged above, that's five real bugs/refinements caught by actual UI testing on this feature, versus zero caught by `tsc` + the four automated suites. Kept as the concrete evidence in this project for why the manual click-through step matters as its own, separate check.
